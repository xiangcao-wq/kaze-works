## 01　ATELIER 84

### 从一张书桌开始。

我的个人网站是一张可以操作的书桌。挑一张软盘，放进 Macintosh，读一段介绍，再打开作品。把浏览个人主页，变成一次小小的探索。

## 02　MORE

### 照片，也可以有很多面。

把照片和视频放到一个立体形状上。转一转、换个形状，从新的角度看熟悉的画面。喜欢的组合可以保存，也可以导出成一张图片。

[![MORE：照片与视频铺在立体形状的不同面上](images/more.jpg)](https://zhaoye.org/more/)

## 03　EXPOSURE

### 用照片，留下一间属于你的房间。

走进一间白色房间，把照片投射到墙面和画布上。边走边看，让画面一点点留下痕迹，最后截一张图带走。

[![EXPOSURE：在白色房间里将照片投射到画布上](images/exposure.jpg)](https://zhaoye.org/exposure/)
